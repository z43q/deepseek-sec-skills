# 安全知识自动化学习 Skill

基于公开平台的安全内容采集与AI辅助分析，**不是漏洞挖掘，是知识学习**。

## 核心原则

- 只采集公开内容，不登录、不绕过任何访问限制
- 不抓取付费/私密内容
- 分析结果沉淀到经验文档，持续扩充攻击模式库
- 每次学习聚焦一个主题（如：某CVE、某漏洞类型、某厂商复盘）

## 采集流程

### 流程1：关键词搜索 → 内容提取 → AI分析

```
1. 搜索关键词 → 获取URL列表
2. 抓取文章内容（限前5篇）
3. AI 阅读每篇 → 提取:
   - 漏洞类型
   - 攻击步骤
   - 利用条件
   - 修复方案
4. 对比已有经验文档 → 找新攻击模式
5. 沉淀到经验文档（标注来源+日期）
```

### 流程2：GitHub PoC 分析

```
1. 搜索 "site:github.com {CVE-ID} exploit"
2. 获取 README.md
3. AI 分析 PoC 原理 → 提取可复用的攻击技术
4. 判断是否适用于已有攻击链库
```

### 流程3：视频内容采集

```
1. 搜索相关关键词
2. 获取视频简介+评论区
3. 如视频含截图/PPT → 截图 → 视觉模型分析
4. 提取技术要点
```

## AI 分析模板

每次采集完后，AI 回答以下问题：

```
1. 本文描述的是什么漏洞？
2. 攻击链是什么？（按步骤列出）
3. 利用条件：需要什么前置条件？
4. 这个漏洞/技巧在攻击链库中有没有对应？
5. 能不能提炼成一条新的攻击链模板？
6. 防御/修复方案是什么？
7. 分值：这个知识对挖洞的实用价值（1-5）
```

